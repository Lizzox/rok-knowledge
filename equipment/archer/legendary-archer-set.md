# Legendary Archer 4-Piece Set + Special Talent Weapon

## Overview
The full 4-piece Legendary Archer set combined with a Special Talent weapon is the recommended endgame build for accounts running Archer-specialty skill-damage commanders (Yi Seong-Gye, Zhuge Liang, Hermann Prime) as their primary march type.

## Stats
> Exact per-piece stat values not independently verified this pass.

- Full set: 4 armor/accessory pieces + weapon
- Rarity: Legendary
- Special Talent weapon variant: adds up to a reported +25% attack bonus when the random forge proc succeeds

## Best Users
Archer-specialty active-skill-damage commanders — specifically called out: Yi Seong-Gye, Zhuge Liang, Hermann Prime.

## Best Pairings
Should be prioritized over the Cavalry set specifically when Archer is the account's primary march type, since it maximizes these commanders' active skill damage multipliers.

## Crafting Priority
Complete the full 4-piece set before chasing the Special Talent weapon proc — the set bonus multiplies the value of the eventual Special Talent roll.

## F2P Alternatives
Gold/Purple Archer sets without the Special Talent proc still provide most of the base stat value; the Special Talent is a bonus layer on top, not a prerequisite for basic viability.

## Endgame Evaluation
Top priority for archer-primary endgame accounts; the Special Talent weapon proc (+30% bonus to attribute bonuses when worn by a commander with the matching talent tree, per the exclusive-effect system) is a long-term forging/refinement goal rather than a first-week target.
