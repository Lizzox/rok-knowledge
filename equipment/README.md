# Equipment

This folder holds one file per named equipment set/piece, following [`schemas/equipment-schema.json`](../schemas/equipment-schema.json), organized into `infantry/`, `cavalry/`, `archer/`, `leadership/`, `mixed/`, `gathering/`, and `accessories/`.

**Status:** populated with the current top-tier named Legendary pieces cited across multiple high-spender build guides (Hammer of the Sun and Moon, Conqueror's Helm, Eternal Knight set, Karuak's Humility, Pride of the Khan, Hope Cloak, Navar's Control, Ash of the Dawn, the Legendary Archer set, The Bard's Pendant, Pendant of Eternal Night, Ring of Doom, Horn of Fury, Scolas' Lucky Coin, Vengeance). This is representative, not exhaustive — RoK has many more Purple/Gold-tier pieces not yet individually filed. General system documentation lives in [`mechanics/equipment.md`](../mechanics/equipment.md); role-based and progression-stage guidance lives in [`guides/equipment/`](../guides/equipment/). The structured data contract is at [`data/equipment.json`](../data/equipment.json).

Contributions adding verified equipment-set detail files here are welcome — see [CONTRIBUTING.md](../CONTRIBUTING.md).
