# Events

This folder holds one file per event, following [`schemas/event-schema.json`](../schemas/event-schema.json), organized into `commander-events/`, `alliance-events/`, `solo-events/`, `seasonal-events/`, and `special-events/`.

**Status:** populated with 11 events — Wheel of Fortune, The Mightiest Governor, Ark of Osiris, Lucerne Scrolls, Sunset Canyon, The Karuak Ceremony, Silk Road Speculators, Shadow Legion, Ceroli Crisis, Alliance Mobilization, and Clarion Call — each covering mechanics, requirements, rewards, F2P/spending strategy, and common mistakes. Shadow Legion and Clarion Call are marked `stub-pending-research` (existence confirmed via community event-calendar tracking, current-run mechanics not independently verified). Exact reward numbers, thresholds, and schedules rotate frequently — cross-check in-game before relying on specific figures. Narrative/strategic overviews for the highest-profile events also remain in [`guides/events/`](../guides/events/) for backward compatibility.

See [`data/events.json`](../data/events.json) for the generated structured data.
