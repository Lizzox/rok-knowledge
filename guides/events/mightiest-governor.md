# Mightiest Governor Event

## Overview
Mightiest Governor is a multi-day individual scoring event (typically several sub-events across categories like gathering, growth/building, research, and combat/kills) culminating in a final ranking within your kingdom.

## Recommended Usage
- Plan resource/speedup stockpiles *before* the event begins so you can burn them during the specific sub-event day they count toward (e.g., save construction speedups for the "growth" day, not before).
- Focus effort on sub-events where you have a clear competitive edge (e.g., a gathering-focused player should not over-invest in the combat day).
- Coordinate with alliance-mates to avoid directly competing for the same barbarian/resource targets during scoring windows.

## Note on Completeness
Exact sub-event names/order and scoring formulas vary between event runs; **verify the current event's specific schedule in-game**.
