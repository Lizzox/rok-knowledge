# Wheel of Fortune Event

## Overview
Wheel of Fortune is a recurring gacha-style event where players spend a currency (often earned via event tasks or purchased) to spin a wheel for rewards including commander sculptures, resources, and speedups, usually with a pity/guarantee mechanic for top-tier rewards after enough spins.

## Recommended Usage
- Complete all free-currency-granting event tasks before spending any purchased currency — free spins should always be exhausted first.
- Check the guaranteed-pity threshold before deciding whether to spend further; near-threshold spending is far more efficient than starting a fresh cycle.
- Prioritize spinning during instances where the featured commander sculpture is one you actually need for your build.

## Note on Completeness
Exact spin costs, odds, and pity thresholds vary by event run; **verify current values in-game** before budgeting spend.
