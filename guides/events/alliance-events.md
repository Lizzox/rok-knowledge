# Alliance Events Overview

## Overview
Alliance-wide events (e.g., Alliance Mobilization, Alliance Fort/Territory battles) reward collective participation — task completion, resource contribution, or combat objectives — with rewards distributed to all contributing members, often scaled by individual contribution rank.

## Recommended Usage
- Complete alliance mobilization tasks daily even in small amounts — consistent participation compounds into strong rewards over an event's full duration.
- Contribute to alliance territory/fort battles according to your role (economy players can gather/build; combat players should focus on defense/attack tasks) rather than everyone attempting the same task type.
- Check alliance leadership announcements for prioritized targets/tasks before self-directing your event participation.

## Note on Completeness
Specific alliance event types and reward structures vary between kingdoms and updates; **verify current event details via your alliance's announcements**.
