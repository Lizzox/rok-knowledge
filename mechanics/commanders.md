# Commander System Overview

## Overview
Commanders are the heroes players recruit, train, and dispatch to lead marches, defend cities, and gather resources in Rise of Kingdoms. Every commander belongs to one of four rarities (Legendary, Epic, Elite, Advanced), one or more civilizations, and has a set of **specialties** that determine which talent trees are available and which roles the commander is naturally suited for.

## Rarity Tiers
- **Legendary** — the most powerful and hardest to obtain (Golden Heads / Legendary sculptures, events, VIP shop). Full skill sets, strongest talent trees, mastery skill included.
- **Epic** — strong all-round commanders obtainable via Epic Wheel, events, and gold Epic sculptures.
- **Elite** — obtainable early via gems/gold or specific events; useful in the early-to-mid game and for garrisons/gathering.
- **Advanced** — starting commanders, weakest tier, mainly used briefly at the very start of the game.

## Specialties
Each commander has 1–3 specialties from: Infantry, Cavalry, Archer, Leadership, Skill, Garrison, Support, Conquering, Peace-time Skills (research/construction/training speed). Specialties gate which talent tree branches (e.g., Infantry tree, Skill tree) a commander can invest points into.

## Star Level and Skills
Commanders start at 1-star with one active skill. Feeding Skill Books raises star level (1★–5★ typically, some to 6★ via Sculpting/Insight books), unlocking additional skills at 2★, 3★, 4★, and a 5th "mastery" skill for Epic/Legendary commanders at max star (via Insight/Mastery books). Skills are Active (triggered manually) or Passive (always-on modifiers to damage, rage, defense, etc.).

## Talents
Talent points are earned via Talent Books (Universal Talent Books work on any commander; specific books also exist). Trees are branch-specific (e.g., Infantry, Cavalry, Skill, Support). Talent trees can be reset for free.

## Expertise
Some commanders unlock an **Expertise** skill tree (post-Skill-Tree Redux update) offering additional passive bonuses on top of base skills/talents, gated by expertise level requiring Expertise materials.

## Pairing (Primary + Secondary Commander)
Marches can be led by up to two commanders: a Primary (front) and Secondary (rear). Skills, talents, and expertise from both apply, but skill *activation* order and rage generation are primarily driven by the primary commander in most game modes. Choosing complementary specialties (e.g., a damage-focused primary with a rage-generation/utility secondary) is the core of "pairing" strategy.
