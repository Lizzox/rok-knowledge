# Rage System

## Overview
Rage is the resource consumed to trigger a commander's active skill in combat. Rage builds automatically each combat round (from base regeneration plus talent/skill/equipment bonuses) and is capped at 1000 for most game modes.

## Statistics
- Base rage generation per round is fixed; talents, skills (e.g., Sun Tzu's rage-generation buff), and expertise nodes increase the rate.
- Active skills typically cost a fixed rage amount (commonly ~1000 for primary "ultimate" skills) — check each commander's skill description for the exact number.
- The primary (front) commander's rage bar is typically what governs when the march's active skill fires in most PvE/PvP combat.

## Recommended Usage
- Rage-generation support commanders (e.g., Sun Tzu, Boudica) are prized as secondary picks because they let the primary commander's skill fire more often, increasing overall damage/utility uptime.
- Rally leaders benefit heavily from rage-focused talents/equipment since their skill triggering affects the entire rallying force's shared combat outcome in many contexts.
