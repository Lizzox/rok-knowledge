# Attila + Yi Seong-Gye

## Purpose
Efficient farming of regular barbarian camps by clearing multiple weaker enemies quickly with AoE skill damage.

## Explanation
Attila's AoE active skill hits several barbarians per activation, and Yi Seong-Gye's passives amplify that skill damage, reducing the number of skill activations (and therefore time) needed to clear a camp — improving farming throughput per march sent.

## Strengths
- Fast clear times on grouped/lower-level barbarian spawns.
- Reuses the same core commanders players already build for open-field PvP, minimizing extra investment.

## Weaknesses
- Overkill for very low-level barbarians where any competent march would succeed; best reserved for higher-level barbarian farming where speed matters for troop training/skillbook rewards.

## Alternatives
- Any strong AoE-skill Cavalry or Archer commander (e.g., Zhuge Liang) can substitute as primary.
