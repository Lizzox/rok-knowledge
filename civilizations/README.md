# Civilizations

This folder holds one file per playable civilization, following [`schemas/civilization-schema.json`](../schemas/civilization-schema.json).

**Status:** populated with all 15 known civilizations (China, Rome, Britain, Germany, Arabia, Japan, Korea, Spain, Ottoman, Byzantium, Vikings, France, Egypt, Maya, Greece), each with real, sourced bonus values and role recommendations. Exact bonus percentages should still be cross-checked in-game, since civilization balance is periodically revised — each file is marked `detail_status: partial` accordingly. See [`guides/beginner/civilization-choice.md`](../guides/beginner/civilization-choice.md) for the general mechanic writeup and [`data/civilizations.json`](../data/civilizations.json) for the generated structured data.

Contributions verifying exact current bonus percentages in-game are welcome — see [CONTRIBUTING.md](../CONTRIBUTING.md).
