# Civilizations

This folder holds one file per playable civilization (China, Rome, Britain, Germany, Arabia, Japan, Korea, Spain, Ottoman, Byzantium, Vikings, France, and others added over time), documenting their starting bonus, thematic identity, and notable civilization-locked commanders.

**Status:** stub — civilization-specific bonus values change periodically and were not independently verified for this pass. See [`guides/beginner/civilization-choice.md`](../guides/beginner/civilization-choice.md) for the general mechanic writeup, and [`data/civilizations.json`](../data/civilizations.json) for the structured (partial) roster.

Contributions adding verified per-civilization detail files here are welcome — see [CONTRIBUTING.md](../CONTRIBUTING.md).
