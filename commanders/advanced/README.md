# Advanced Commanders

Advanced-rarity commanders (e.g., the starting commanders granted to every new governor at the beginning of the game) are the weakest tier and are typically replaced within the first few days of play once Elite/Epic commanders are unlocked.

Because they have negligible long-term strategic relevance, this repository does not maintain individual detail files for them. If you need one documented, open an issue/PR per [CONTRIBUTING.md](../../CONTRIBUTING.md) — this is a `stub-pending-research` gap, not an oversight.
